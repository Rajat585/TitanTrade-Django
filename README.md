**TitanTrade-Django**
Titan Trade - A Django based stock market dashboard with separate admin and user login, admin-to-admin creation, and integrated email notifications. Features include authentication, recruiter-ready UI/UX, and database-backed storage.
**A professional stock market dashboard built with Django, featuring:**
- Separate login for Admin and Users
- Admin can create new Admin accounts
- Integrated email notifications
- User authentication (signup/login/logout)
- Neat recruiter-friendly UI/UX
- Database-backed persistent storage
- Error handling and success pages
